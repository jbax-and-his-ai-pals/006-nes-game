# Archived NES Prototype

`jerbs-nes-prototype-2026-08-21.zip` is a source-and-ROM snapshot of the
completed exploration/combat prototype, including its tools, tests, and
documentation. `ROADMAP-nes-prototype.md` preserves the roadmap that was
active when the project changed direction.

The active `ROADMAP.md` now describes the new neon-night graphic-adventure
direction.
